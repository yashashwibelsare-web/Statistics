# Statistical Analysis Using Python

## About the Project

Statistics helps us understand data, identify patterns, and make better decisions. In this project, I worked on different statistical concepts using Python to understand how numerical data can be analyzed and interpreted.

The project focuses on calculating central tendency, studying data distribution, identifying outliers, and performing statistical measurements. I also worked on confidence interval problems and hypothesis testing using practical examples from different fields.

## Project Objectives

The main objective of this project was to apply statistical concepts to numerical data and understand how they are useful in real-world situations. I worked on finding mean, median, and mode, analyzing skewness, detecting and removing outliers, calculating statistical metrics, constructing confidence intervals, and performing hypothesis testing.

## Tools and Technologies Used

I used Python in Jupyter Notebook to perform the statistical analysis. Pandas and NumPy were used for handling numerical data and calculations, while Matplotlib and Seaborn were used to create graphs and visualize data distributions.

## Work Performed

### 1. Central Tendency

I calculated the mean, median, and mode of numerical parameters to understand the average values and distribution of the data.

### 2. Skewness Analysis

I studied the skewness of numerical data to understand its distribution and used KDE plots to visualize the shape of the data.

### 3. Outlier Detection

I identified outliers in numerical parameters and worked on removing them to understand how extreme values can affect statistical analysis.

### 4. Statistical Metrics

I calculated different statistical measurements, including standard deviation, correlation, variance, and percentiles, to understand the spread and relationship between numerical values.

### 5. Statistical Visualization

I created different graphs, including histograms, scatter plots, pairplots, and swarm plots, to explore data patterns and relationships visually.

### 6. Confidence Interval (CI)

I solved confidence interval problems using sample data and sample standard deviation. The assignment included three practical examples:

- Smartphone Screen Time – 90% confidence interval.
- Delivery Time – 95% confidence interval.
- Student Study Hours – 99% confidence interval.

### 7. Hypothesis Testing

I worked on hypothesis testing problems to evaluate whether actual processing times increased beyond their predicted values. The assignment included two business examples:

- AutoDrive Components Ltd. – Engine Assembly Time.
- FreshBake Foods Pvt. Ltd. – Baking Time Evaluation.

These examples helped me understand how statistical methods can be applied to evaluate real-world business processes.

## Key Learnings

While completing this project, I improved my understanding of statistical concepts and their practical implementation using Python. I gained experience in calculating statistical measures, understanding data distributions, identifying outliers, creating visualizations, constructing confidence intervals, and performing hypothesis testing.

## Conclusion

This project gave me an opportunity to apply statistical concepts to practical problems using Python. It helped me understand how numerical data can be analyzed, interpreted, and used to make meaningful decisions. Overall, I strengthened my statistical knowledge and gained practical experience in data analysis using Python.
